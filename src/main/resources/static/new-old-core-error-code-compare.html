📌 颜色说明

新增（绿色）- 整行标绿：新版本新增的错误码

💡 使用说明

  • 文件说明：
    • 左边：旧版本错误码excel（Excel格式）
    • 右边：新版本错误码excel（Excel格式）
    • 表头固定在第 1 行（A~G 共 7 列），数据从第 2 行开始；表头不符合会直接报错并指出哪一列不对
    • 文件含多个 sheet 时会先提示"只比对第一个 sheet"，确认后才开始比对；取消则不比对
  • 唯一键与比对范围：
    • 唯一键：交易码 + 新响应码（A + D 列）
    • 比对列：交易名称(B)、分组(C)、新响应码错误描述(E)、调用方SOP格式调用防腐交易响应码(F)、调用方SOAP/JSON格式调用防腐交易响应码(G)
    • 比较前统一去掉首尾空格；同一「交易码 + 新响应码」重复时后行覆盖前行（日志告警）
    • 缺少交易码或新响应码的行会被跳过，并在结果统计里给出跳过行数
  • 变更标记：
    • ✅ 新增：新版本独有的错误码，整行标绿
    • ✏️ 修改：仅变化的列标黄，结果 sheet 显示新值，旧值→新值写在修订明细里
    • ❌ 删除：旧版本独有的错误码，不在结果 sheet 追加行，仅登记到「修订记录」
  • 修订记录格式（5 列）：
    • A列：交易码
    • B列：新响应码
    • C列：修订级别（固定为"错误码"）
    • D列：修订方式（新增/修改/删除，带颜色标记）
    • E列：修订明细（形如「列名: 旧值 → 新值」，多列用分号分隔，带双向超链接）
  • 超链接：
    • 修订记录 → 结果 sheet 对应行（正向链接）
    • 结果 sheet 对应行 → 修订记录（反向链接）
