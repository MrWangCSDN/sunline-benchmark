💡 使用说明

  • 文件说明：
    • 左边：旧版本核心接口文档（Excel格式）
    • 右边：新版本核心接口文档（Excel格式）
    • 填写"排除 Sheet"可跳过指定 sheet 页（如说明、修订记录、索引等），不参与比对
  • Sheet页比对规则：
    • 旧版本多出的sheet：标记为"接口新增"（绿色）
    • 新版本多出的sheet：忽略，不做任何处理
    • Sheet名称相同：进行字段级别比对
  • 字段变更标记：
    • ✅ 字段新增：绿色背景显示
    • ✏️ 字段修改：黄色背景显示最新值
    • ❌ 字段删除：灰色背景+删除线，显示在sheet页最下面
  • 修订记录格式：
    • A列：接口名
    • B列：修订级别（接口/字段）
    • C列：修订方式（新增/删除/修改，带颜色标记）
    • D列：修订明细（带双向超链接）
  • 超链接：
    • 修订记录 → 目标接口字段行（正向链接）
    • 接口字段行 → 修订记录（反向链接）
