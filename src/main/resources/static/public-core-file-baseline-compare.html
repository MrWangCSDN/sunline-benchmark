💡 使用说明

  • 比对范围：只比对名为 EFT文件基线 的 sheet 页；其他 sheet 原样复制不参与比对。
  • 匹配规则：从第 2 行开始，以 A 列内容（528核心全路径文件名）为唯一键，进行整行匹配。
  • 表头行：第 1 行作为表头；如果基线和对比文件的列数不一致，取两侧并集进行比较。
  • 差异标记：
    • ✅ 行新增：整行标绿（出现在对比文件、基线没有）
    • ✏️ 行修改：仅差异列标黄，明细在修订记录展开
    • ❌ 行删除：仅在修订记录中体现，结果文件不复制旧行
  • 修订记录：4 列 — EFT文件基线 / 文件基线 / 新增（或修改、删除）/ 明细 + 双向超链接。
  • 异常提示：任一文件无 EFT文件基线 sheet → 抛错终止比对。
